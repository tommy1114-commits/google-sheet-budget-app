# 📐 試算表結構與公式設計解析 (Sheet Architecture)

本文件詳細說明《Google Sheet 雙幣記帳與連動資產管理》中 **7 張核心工作表** 的欄位結構、公式設計原理與資料流向，方便想要深度客製化或二次開發的使用者參考。

---

## 📊 7 大工作表總覽

| 順序 | 工作表名稱 | 核心角色 | 與 Apps Script 的互動 |
| :--- | :--- | :--- | :--- |
| **1** | **帳戶名單** | 管理台幣/美金帳戶初始金額、即時餘額、總資產與各月底存錢目標 | `getInitData()`、`getFullAccountBalances()` 讀取 |
| **2** | **預算進度** | 抓取即時匯率、計算當月/今日剩餘預算、繪製 `SPARKLINE` 雙色進度條 | `rates_()`、`getInitData()` 讀取；`calculateDailyBudget()` 每日寫入 `G6, G8` |
| **3** | **選單設定** | 定義記帳時的「預算分類 (A欄)」與「詳細項目 (B欄)」二階連動選單 | `getCategoryMapping()` 讀取 |
| **4** | **流水帳** | 系統核心交易資料庫，所有支出、收入、轉帳、餘額校準、固定扣款皆寫入此表 | `saveTransaction()`、`saveIncome()`、`saveTransfer()`、`processAdjustment()`、`updateTransaction()`、`deleteTransaction()` 讀寫 |
| **5** | **月份查詢看板** | 透過 `QUERY` 與 `MAP/LAMBDA` 動態篩選指定年月的交易明細與每日收支趨勢圖 | 純試算表公式自動連動，供電腦端檢視分析 |
| **6** | **固定扣款設定** | 設定每月固定日自動扣款的訂閱與帳單清單 | `autoProcessFixedExpenses()` 每日凌晨讀取檢查 |
| **7** | **每月金流規劃** | 個人月度收入、固定訂閱、一般預算與儲蓄配置藍圖試算表 | 純試算表規劃輔助工具 |

## 💡 核心設計巧思：為什麼「流水帳」要分 E 欄與 H 欄？

打開 **「流水帳」** 工作表時，您會發現有兩個金額欄位：
- **`E 欄（金額 / 折合台幣預算支出）`**
- **`H 欄（H 原始金額 (必加)）`**

這是整套系統能夠同時完美處理 **「多幣別記帳」、「不影響預算的轉帳/收入/校準」與「多幣別帳戶餘額結算」** 的關鍵設計：

| 交易類型 | E 欄（台幣預算支出金額） | H 欄（帳戶原始金額） | 設計目的 |
| :--- | :--- | :--- | :--- |
| **一般/特支 支出 (TWD)** | `金額` (如 `150`) | `金額` (如 `150`) | 同時計入當月台幣預算消耗（E欄），並從該台幣帳戶扣除餘額（H欄）。 |
| **一般/特支 支出 (USD/JPY)** | `原幣金額 × 即時匯率` | `原幣金額` | **E 欄**自動換成台幣計入月預算；**H 欄**保留原幣金額（若用美金帳戶扣款即可精準扣除美金）。 |
| **收入** | `0` | `實際入帳金額` | **E 欄設為 `0`** 避免沖銷或干擾當月支出預算；**H 欄**讓入帳帳戶餘額正確增加。 |
| **帳戶間轉帳** | `0`（轉出與轉入皆為 `0`） | `轉帳金額` | 轉帳只是資產在自己帳戶間移動，並非花費，故 **E 欄為 `0`**，僅透過 **H 欄** 一減一加更新兩帳戶餘額。 |
| **餘額校準** | `0` | `差額絕對值` | 手動校準皮夾或銀行誤差時，透過 **H 欄** 補齊帳戶餘額，**E 欄為 `0`** 避免突發誤差打亂今日可用預算。 |

## 🔍 各工作表關鍵公式詳解

### 1. 【帳戶名單】工作表
- **各帳戶目前餘額 (`C2:C19` 台幣、`C22:C25` 美金)**：
  ```excel
  =B2 + SUMIFS('流水帳'!H:H, '流水帳'!F:F, A2, '流水帳'!C:C, "收入") - SUMIFS('流水帳'!H:H, '流水帳'!F:F, A2, '流水帳'!C:C, "支出")
  ```
  > 原理：`初始金額 (B欄)` ＋ `流水帳中該帳戶的所有收入 (含轉入、正向校準)` － `流水帳中該帳戶的所有支出 (含轉出、負向校準)`。
- **台幣總資產 (`I13`)**：`=SUM(C2:C19)`
- **美金總資產 (`I16`)**：`=SUM(C22:C25)`
- **美金換算台幣 (`J16`)**：`=GOOGLEFINANCE("CURRENCY:USDTWD") * I16`
- **現金總資產 (`I19`)**：`=I13 + J16`
- **保底總資產 (`I22`)**：`=I19 - C15`（預設扣除 `C15` 專款旅遊基金帳戶，可依需求自行修改公式）。
- **股票未實現淨利 (`K22`)**：預設填入示範數值 `50000`。若您有另一份 Google 試算表專門記錄股票損益，可使用 `=IMPORTRANGE("您的股票試算表網址", "工作表名稱!儲存格")` 自動連動！

---

### 2. 【預算進度】工作表
- **即時匯率 (`J1`, `J2`)**：
  - `J1` (美金)：`=GOOGLEFINANCE("CURRENCY:USDTWD")`
  - `J2` (日幣)：`=GOOGLEFINANCE("CURRENCY:JPYTWD")`
- **當月一般性支出 (`B6`) 與特支費支出 (`B8`)**：
  ```excel
  =SUMIFS('流水帳'!E:E, '流水帳'!B:B, "一般花費", '流水帳'!A:A, ">="&DATE(YEAR(TODAY()), MONTH(TODAY()), 1))
  ```
- **今日起始額度 (`G6`, `G8`) 與今日剩餘預算 (`F6`, `F8`)**：
  - 每天早上 6:00 由 Apps Script 的 `calculateDailyBudget()` 自動計算：
    $$\text{今日起始額度 (G6)} = \max\left(0, \text{round}\left(\frac{\text{當月剩餘預算 (D6)}}{\text{本月剩餘天數}}\right)\right)$$
  - 而 `F6`（今日一般預算剩餘）則用公式即時扣除「今天已經記帳的一般花費」：
    ```excel
    =G6 - SUMIFS('流水帳'!E:E, '流水帳'!B:B, "一般花費", '流水帳'!A:A, ">="&TODAY(), '流水帳'!A:A, "<"&TODAY()+1)
    ```
- **視覺化時間進度比對條 (`A13`, `A18`)**：
  利用 Google 試算表獨有的 `SPARKLINE` 橫條圖，將「目前花費比例 (`C6`)」與「當月時間進度 (`DAY(TODAY())/DAY(EOMONTH(TODAY(),0))`)」疊加顯示，中間以一條紅線 (`#FF0000`) 標示今日時間基準線。

### 3. 【月份查詢看板】工作表
- **動態月份交易清單 (`A4`)**：
  根據使用者在 `B1`（年份）與 `D1`（月份）輸入的數值，自動從 `流水帳` 撈出該月所有紀錄並依日期由新到舊排序：
  ```excel
  =QUERY('流水帳'!A:H, "SELECT * WHERE A IS NOT NULL AND YEAR(A) = " & B1 & " AND MONTH(A) = " & (D1-1) & " ORDER BY A DESC", 1)
  ```
  *(註：Google Sheets `QUERY` 語法中的 `MONTH(A)` 為 0 基索引，1 月為 0、10 月為 9，因此公式寫為 `D1-1`)*。
- **當月每日收支統計序列 (`J5:L5`)**：
  - `J5` 使用 `=SEQUENCE(DAY(EOMONTH(DATE(B1,D1,1),0)), 1, DATE(B1,D1,1))` 自動產生該月 1 號到月底的所有日期。
  - `K5` 與 `L5` 使用 `MAP(..., LAMBDA(d, SUMIFS(...)))` 動態計算每一天的總支出與總收入，並自動連動繪製下方的長條趨勢圖！

### 4. ✈️ 專案/旅遊獨立統計技巧（【選單設定】＋【流水帳】I 欄）
若您計畫出國旅遊（例如「2026日本行」），不想讓旅費混入日常的「一般花費」或「特支費」預算中：
1. 在 **「選單設定」** 的 A 欄新增分類名稱（例如 `✈️出國旅遊專案`），B 欄列出子項目（早餐、交通、購物、住宿等）。
2. 當您在 App 記帳選擇 `✈️出國旅遊專案` 分類時，`Code.gs` 會自動將分類名稱寫入 `流水帳` 的 **B 欄與 I 欄**。
3. 在 `流水帳` 右側 `K3` 儲存格即可使用：
   ```excel
   =SUMIFS('流水帳'!E:E, '流水帳'!C:C, "支出", '流水帳'!I:I, "✈️出國旅遊專案")
   ```
   一眼統計整趟旅程折合台幣的總花費，且完全不會扣到當月日常一般預算！
